# FRAUD SHIELD API Documentation

The FRAUD SHIELD backend exposes a RESTful API powered by FastAPI.

- **Base URL:** `http://127.0.0.1:8000`
- **Interactive OpenAPI Documentation:** `http://127.0.0.1:8000/docs`
- **Alternative ReDoc Documentation:** `http://127.0.0.1:8000/redoc`

---

## Endpoints Summary

| Method | Endpoint | Description |
|:---:|:---|:---|
| `POST` | `/api/predict` | Evaluate transaction fraud probability and obtain plain-language reasons |
| `GET` | `/api/health` | Check API health, model loading status, version, and uptime |
| `GET` | `/api/model-info` | Retrieve model specifications and notebook benchmark results |
| `GET` | `/` | Serve UI with in-memory injected bridge script |
| `GET` | `/bridge.js` | Serve client integration bridge JavaScript |

---

## 1. POST `/api/predict`

Evaluates transaction input parameters through the feature engineering pipeline and the trained Random Forest model.

### Request Headers
- `Content-Type: application/json`

### Request Body Schema
```json
{
  "type": "TRANSFER",
  "amount": 250.0,
  "sender_balance": 5000.0,
  "recipient_balance": 3200.0,
  "time": "14:30"
}
```

#### Field Specifications:
- `type` *(string, required)*: Transaction type. Must be either `"TRANSFER"` or `"CASH_OUT"`.
- `amount` *(float, required)*: Transaction value in rupees. Must satisfy: $1.0 \le \text{amount} \le 1,000,000.0$.
- `sender_balance` *(float, required)*: Pre-transaction sender balance. Must satisfy: $0.0 \le \text{sender\_balance} \le 10,000,000.0$.
- `recipient_balance` *(float, required)*: Pre-transaction recipient balance. Must satisfy: $0.0 \le \text{recipient\_balance} \le 10,000,000.0$.
- `time` *(string, required)*: 24-hour time string in `HH:MM` format (e.g., `"14:30"` or `"02:15"`).

---

### Response (200 OK)
```json
{
  "risk": 0.0,
  "verdict": "CLEARED",
  "threshold": 0.5,
  "reasons": [
    {
      "level": 0,
      "text": "The amount is small compared with the sender's balance.",
      "signal": "balance_behavior"
    },
    {
      "level": 0,
      "text": "Sent at a normal time of day.",
      "signal": "time_pattern"
    },
    {
      "level": 0,
      "text": "Direct transfer between accounts within standard clearing parameters.",
      "signal": "transaction_type"
    },
    {
      "level": 0,
      "text": "Standard transaction amount within ordinary operational bounds.",
      "signal": "amount_pattern"
    }
  ],
  "model": "RandomForestClassifier",
  "latency_ms": 38.45
}
```

#### Response Fields:
- `risk` *(float)*: Predicted fraud probability ($0.0 \dots 1.0$) generated by `model.predict_proba`.
- `verdict` *(string)*: `"FLAGGED"` if `risk >= threshold`, else `"CLEARED"`.
- `threshold` *(float)*: Classification cutoff defined in server configuration (default: `0.50`).
- `reasons` *(array)*: Explanatory telemetry factors sorted by severity descending.
  - `level` *(integer)*: `0` = normal, `1` = mild warning, `2` = strong warning.
  - `text` *(string)*: Plain-language, non-technical explanation.
  - `signal` *(string)*: One of `amount_pattern`, `balance_behavior`, `transaction_type`, `time_pattern`.
- `model` *(string)*: Serialized model class name (`RandomForestClassifier`).
- `latency_ms` *(float)*: Total inference and explanation pipeline execution time in milliseconds.

---

### Sample Fraud Example
#### Request:
```bash
curl -X POST "http://127.0.0.1:8000/api/predict" \
     -H "Content-Type: application/json" \
     -d '{
       "type": "CASH_OUT",
       "amount": 9800.0,
       "sender_balance": 10000.0,
       "recipient_balance": 0.0,
       "time": "02:15"
     }'
```

```json
  "threshold": 0.5,

      "level": 2,
      "text": "Most of the sender's balance (97%) is being moved in one go.",
      "signal": "balance_behavior"
    },
    {

      "signal": "balance_behavior"
    },

      "signal": "time_pattern"
    },

      "signal": "transaction_type"

```

### Validation Error (422 Unprocessable Entity)
When request inputs violate domain limits or format rules:
```json
{
  "detail": [
    "amount: Value error, Amount must be at least ₹1.",
    "time: Value error, Time must be in 24-hour HH:MM format (e.g., '14:30' or '02:15')."
  ],
  "message": "Input validation failed."
}
```

## 2. GET `/api/health`

Returns operational readiness of the API and loaded model.

### Request:
```bash
curl -X GET "http://127.0.0.1:8000/api/health"
```

### Response (200 OK):
```json
{
  "status": "ok",
  "model_loaded": true,
  "model_name": "RandomForestClassifier",
  "version": "1.0.0",
  "uptime_seconds": 142.85
}
```

## 4. GET `/`

Serves `frontend/index.html` with `<script src="/bridge.js"></script>` injected in-memory before `</body>`. The file on disk is never modified.

### Response (200 OK):
- Content-Type: `text/html; charset=utf-8`

---

## 5. GET `/bridge.js`

Serves the integration bridge JavaScript module.

### Response (200 OK):
- Content-Type: `application/javascript; charset=utf-8`
