HOW AI WORKS

Data → Features → ML → Prediction.

Every transaction is decomposed into a handful of signals, then scored by an ensemble of models. Three of the strongest signals:

Spending Speed How fast money is moving compared to this account's usual hourly pattern.
Location Mismatch Whether the claimed location is physically possible given recent activity.
Unusual Amount How far this transaction is from the account's typical size.
